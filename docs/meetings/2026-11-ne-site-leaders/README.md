# NE Site Leader Working Session: From Flags to Ownership (Nov 2026)

60-minute session for the North-East Site Leaders on ownership, proactive routines, and escalation.

| File | Use |
|---|---|
| `00-Facilitator-Guide.pdf` | Presenter only: run of show, scenario answer key, pushback responses, school-level data |
| `01-Deck-From-Flags-to-Ownership.pptx` | The deck to present (import into Google Slides). Speaker notes on every slide |
| `01-Deck-From-Flags-to-Ownership.pdf` | Same deck as a PDF backup |
| `02-Escalation-Protocol.pdf` | One-pager: who to tell and when (tutor → SL → PM → partner admin) |
| `03-Site-Leader-Playbook.pdf` | One-pager: daily / weekly / biweekly SL rhythm and how to prevent each flag |
| `04-Tutor-Daily-Routine.pdf` | One-pager SLs share with tutors: before / during / after, missed-reason guide |
| `05-Scenario-and-Commitment-Cards.pdf` | Print and cut: 8 scenario cards (one set per pair), 2 commitment cards per page |

Data: Pearl records for the NE region (iLearn CMO + Lyndhurst MS), refreshed Nov 3, 2026,
comparing Oct 5–16 and Oct 19–30. Rebuild the deck with `node src/build-deck.js` (needs pptxgenjs);
the handouts are `src/*.html` printed to Letter PDF.
