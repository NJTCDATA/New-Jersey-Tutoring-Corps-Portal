ⓘ Why does the site count in Pearl differ from the SY site total? The total reflects all sites listed in the SY Database, including pilot program sites. Pilot schools operate under a separate program structure and are tracked independently from the main school program in Pearl — they are not included in Pearl session or scholar totals. The SY Database is the authoritative source for site counts; Pearl only reflects schools in the regular program roster.

Document Resource Center

☁️
Google Drive · Shared Repository
NJTC Shared Document Folder
All team documents, policies, and guides are stored here. Upload a file and it becomes visible in the Policies Library automatically.
Open Drive Folder ↗
🔄
Automatic Updates — No Technical Steps
When you upload a new document to the Drive folder, it automatically appears in the Policies & Procedures Library under a ☁️ Google Drive Addition tag — visually distinct from the official Policies & Procedures Manual. This makes it clear which documents are supplemental Drive uploads vs. formally documented policies. Simply upload to Drive and you're done.
01
Open the Drive Folder
Click "Open Drive Folder" above to access the shared NJTC document repository.
02
Upload Your Document
Drag your PDF or file into the folder. Google Drive handles the rest.
03
Set Sharing
Right-click → Share → set to "Anyone with the link" as Viewer so the portal can display it.
04
Appears Instantly
The document will appear in the Policies Library the next time any team member loads the portal.
💡
Need to update an existing document? Replace the file in Drive with the new version. The portal will automatically show the updated modification date in the Policies Library card.
